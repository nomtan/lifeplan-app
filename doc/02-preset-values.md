# Lifeplan App プリセット初期値仕様

最終更新: 2026-09-02

## 1. 方針

本ドキュメントは、初期入力を簡単にするためにアプリが提供する標準プリセット値を定義する。

基本方針:

- すべてのプリセット値はユーザーが上書き可能
- 日本国内向けの一般的な目安として提供する
- 公的統計が存在する項目は可能な限り公的統計を基準にする
- 地域差・所得差・個別差が大きい項目は「概算値」であることをUIに明示する
- 将来的に統計更新に合わせてプリセットのバージョン更新を可能にする
- 既存プランの金額はプリセット更新時に自動変更しない

---

## 2. 教育費

### 2.1 基本設計

文部科学省「令和5年度 子供の学習費調査」の訂正版を基準とする。

ただし同調査の「学習費総額」には学校外活動費（塾・習い事など）が含まれる。

本アプリでは塾・習い事を別モデルとして管理するため、学校プリセットでは原則として以下のみを使用する。

- 学校教育費
- 学校給食費

学校外活動費は別プリセットとして管理する。

### 2.2 幼稚園

年間初期値:

| プリセット | 年額 |
| --- | ---: |
| 公立幼稚園 | 85,000円 |
| 私立幼稚園 | 190,000円 |

内訳の基準:

- 公立: 学校教育費 69,362円 + 学校給食費 15,235円
- 私立: 学校教育費 154,062円 + 学校給食費 35,741円

UIでは端数を丸めた金額を初期値として表示する。

### 2.3 保育園

保育料は自治体・世帯所得・年齢・施設種別による差が非常に大きいため、公的な全国一律額を設定しない。

初期プリセット:

| プリセット | 初期値 |
| --- | ---: |
| 保育園 0〜2歳 | 月額 30,000円 |
| 保育園 3〜5歳 | 月額 0円 |

注意:

- 0〜2歳の30,000円は入力補助用の暫定目安であり、公的全国平均ではない
- 3〜5歳は幼児教育・保育の無償化を前提に保育料0円を初期値とする
- 給食費・延長保育・送迎・用品費等は別途上書きまたは追加支出可能
- 0〜2歳でも住民税非課税世帯等では無償化対象となる場合がある

### 2.7 塾・習い事 / 学校外活動

塾・習い事を個別に細分化した全国一律値ではなく、まず「学校外活動費 標準」プリセットを用意する。

年間初期値:

| 学校段階 | 公立系 | 私立系 |
| --- | ---: | ---: |
| 幼稚園 | 100,000円 | 158,000円 |
| 小学校 | 256,000円 | 710,000円 |
| 中学校 | 356,000円 | 423,000円 |
| 高校 | 245,000円 | 347,000円 |

このプリセットには補助学習・塾・習い事・スポーツ・文化活動等が含まれる。

ユーザーは以下のどちらでも利用可能とする。

1. 「学校外活動費 標準」をそのまま利用
2. 標準値を0円にし、塾・習い事を個別の継続教育費として追加

二重計上を避けるUIガイドを表示する。

### 2.9 大学の自宅外通学 / 一人暮らし

JASSO学生生活調査では、大学学部昼間部のアパート等居住者は自宅居住者より年間学生生活費が約48万円高い。

初期版ではシンプルな「自宅外通学追加費」プリセットを用意する。

| プリセット | 年額 |
| --- | ---: |
| 自宅通学 | 0円 |
| 一人暮らし追加費 | 480,000円 |

必要に応じてユーザーが以下へ分解・上書きできる。

- 家賃
- 光熱費
- 生活費
- 仕送り
- その他

将来的に地域別プリセット（東京圏 / 京阪神 / その他）を追加可能とする。

## 3. 住宅

### 3.1 固定資産税

初期概算式:

```
概算固定資産税年額 = 住宅購入価格 × 70% × 1.4%
```

つまり初期概算として購入価格の約0.98% / 年を提示する。

例:

- 購入価格 4,000万円 → 約392,000円 / 年

注意:

- 実際の課税標準額は購入価格と一致しない
- 土地・建物の評価、軽減措置、新築特例等で大きく変わる
- あくまで入力補助用の概算値
- ユーザー上書きを強く推奨する

### 3.2 持ち家修繕費

戸建て向けの簡易プリセット:

| 購入 / 築年から | 単発修繕費 |
| --- | ---: |
| 10年 | 1,000,000円 |
| 20年 | 1,500,000円 |
| 30年 | 2,000,000円 |

対象イメージ:

- 外壁
- 屋根
- 給湯器
- 水回り
- 設備交換
- その他大規模修繕

マンションは修繕積立金を通常の継続支出として入力することを基本とする。

上記は統計値ではなく、ライフプラン上の支出漏れを防ぐための初期概算プリセットとする。

## 4. 車

### 4.1 標準車両プリセット

初期版では車種クラス別ではなく、「一般的な自家用普通乗用車」1種類を標準プリセットとする。

各車両ごとにすべて上書き可能。

### 4.2 自動車税

標準初期値:

- 年額 36,000円

基準:

- 1.5L超〜2.0L以下の自家用乗用車
- 令和元年10月1日以後初回新規登録の税率

排気量等に合わせてユーザー上書き可能。

### 4.3 車検

標準初期値:

- 2年ごと 100,000円

初回車検時期などは購入年月から自動配置できるようにする。

車両重量・整備内容等による差が大きいため概算値扱い。

### 4.4 任意保険

標準初期値:

- 年額 80,000円

年齢・等級・補償・車種による差が大きいため概算値扱い。

### 4.5 メンテナンス

標準初期値:

- 年額 60,000円

対象例:

- オイル
- タイヤ
- 消耗品
- 定期点検
- 軽微な修理

### 4.6 ガソリン / 充電

標準初期値:

- 月額 10,000円
- 年額換算 120,000円

走行距離・燃費・燃料種別による差が大きいため上書き前提。

### 4.7 駐車場

標準初期値:

- 0円

地域差が非常に大きいため全国一律値は設定せず、ユーザー入力を促す。

### 4.8 車両買い替え

初期版では自動買い替え周期を強制しない。

任意で以下のクイックプリセットを提供する候補とする。

- 7年後
- 10年後
- 13年後

買い替え価格は現在の車両購入価格を初期値としてコピーし、ユーザーが上書きする。

## 5. 投資資産

初期利回りプリセットは、現時点では自動設定しない。

初期値:

| 資産カテゴリ | 想定利回り |
| --- | ---: |
| 現金 / 預金 | 0% |
| 株式 | 0% |
| 投資信託 | 0% |
| NISA | 0% |
| iDeCo | 0% |
| その他投資 | 0% |
| 不動産 | 0% |

理由:

- 将来利回りは保証できない
- 商品ごとの差が大きい
- アプリが投資成果を示唆しているように見えることを避ける

ユーザーが任意で想定利回りを設定する。

## 6. 収入

給与等の年間増加率初期値:

- 0%

ユーザーが任意に設定する。

年金・退職金:

- 自動プリセット金額なし
- ユーザー手入力

---

## 7. 継続支出

インフレ率を初期版では考慮しないため、年間増加率の初期値は以下とする。

- 0%

ユーザーが必要な場合のみ個別に変更する。

## 8. プリセットのバージョン管理

プリセット定義には内部的にバージョンを持たせる。

例:

```
education-jp-2026-v1
housing-jp-2026-v1
vehicle-jp-2026-v1
```

仕様:

- 新規プランには最新プリセットを適用
- 既存プランの保存済み金額は自動更新しない
- 将来的に「最新プリセットとの差額を見る」機能を追加可能
- プリセットには根拠となる統計年度・出典をメタデータとして保持する
