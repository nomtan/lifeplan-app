# Lifeplan App プラン詳細・年表UI仕様

最終更新: 2026-09-02

## 1. 目的

本ドキュメントは、ライフプラン詳細画面に表示する年表UIの構成を定義する。

年表はLifeplan Appの中心機能であり、ユーザーが将来の家計・資産・ライフイベントを年単位で直感的に確認できることを目的とする。

---

## 2. 基本構造

- 年表は横スクロール
- 1列 = 1年
- 西暦と本人年齢を併記
- 家族メンバーの年齢も表示
- 内部計算は月単位
- 表示は年単位に集計

---

## 3. 年表の情報ブロック

年表は以下の4ブロックに分ける。

1. 家族
2. 収支
3. 資産
4. ライフイベント

### 3.1 家族

表示項目:

- 本人年齢
- 配偶者 / パートナー年齢
- 子ども年齢
- 親などその他家族の年齢

### 3.2 収支

通常表示:

- 年間収入合計
- 年間支出合計
- 年間収支

詳細表示ではカテゴリ内訳を展開可能とする。

収入内訳例:

- 給与
- 賞与
- 副業
- 年金
- その他収入

支出内訳例:

- 生活費
- 住宅
- 教育
- 車
- 保険
- その他支出

### 3.3 資産

通常表示:

- 資産合計
- 負債合計
- 純資産

必要に応じて以下もサマリー表示可能:

- 現金合計
- 投資資産合計

詳細表示ではカテゴリ内訳を展開可能とする。

資産内訳:

- 現金 / 預金
- 株式
- 投資信託
- NISA
- iDeCo
- その他投資
- 不動産

### 3.4 ライフイベント

各年に発生する主要イベントを表示する。

例:

- 入学
- 卒業
- 住宅購入
- 修繕
- 車購入 / 買い替え
- 退職
- 資産売却 / 取り崩し
- その他ライフイベント

---

## 4. 折りたたみ仕様

収支・資産は通常時は合計値を表示し、カテゴリ内訳は展開式とする。

目的:

- スマホでも縦方向の情報量を抑える
- 年表の全体像を見やすくする
- 必要な場合のみ詳細確認できるようにする

### 4.1 通常表示

例:

- 収入 650万円
- 支出 520万円
- 年間収支 +130万円
- 資産 2,450万円
- 負債 1,800万円
- 純資産 650万円

### 4.2 収支を展開

例:

- 給与 600万円
- 副業 50万円
- 生活費 300万円
- 住宅費 120万円
- 教育費 60万円
- 車関連費 40万円

### 4.3 資産を展開

例:

- 現金 300万円
- 株式 500万円
- 投資信託 700万円
- NISA 400万円
- iDeCo 150万円
- 不動産 400万円
- 負債 1,800万円

---

## 5. UI方針

- HeroUIを意識したカード・アコーディオン表現
- 通常時は情報密度を抑える
- 合計値を大きく、内訳を小さく表示
- 正の年間収支 / 純資産は視覚的に区別
- 現金残高がマイナスになった年は警告表示
- タップ / クリック領域を十分に確保

---

## 6. Web / Mobile

### Web

- 左側に項目列を固定
- 年の列を横スクロール
- 収支 / 資産ブロックを展開可能
- 複数年を同時に確認しやすい密度で表示

### Mobile

- 同じ横スクロール構造を維持
- 1年セル幅をタッチ操作しやすいサイズにする
- 収支 / 資産は合計値を優先
- 詳細内訳はアコーディオンで展開
- 行ラベルはスクロール中も可能な範囲で追従表示
