# Lifeplan App 資産実績入力UI仕様

最終更新: 2026-09-02

## 1. 目的

本ドキュメントは、資産実績を継続的に記録するための入力UIを定義する。

資産実績はライフプラン上の想定値とは別に管理し、実際の資産推移として蓄積する。

---

## 2. 基本方針

- 月1回程度の入力を推奨する
- 任意の日付でいつでも入力可能
- 新規入力時は直近の実績値を初期値としてコピーする
- ユーザーは変更があったカテゴリだけ修正できる
- 入力は個別口座ではなくカテゴリ単位
- 1画面内で主要カテゴリをまとめて入力できる構成を基本とする
- 入力中は広告を表示しない

---

## 3. 入力項目

### 3.1 基本情報

- 実績日
- メモ（任意）

### 3.2 資産カテゴリ

- 現金 / 預金
- 株式
- 投資信託
- NISA
- iDeCo
- その他投資
- 不動産

### 3.3 負債

- 負債合計

初期版では住宅ローン・自動車ローン・汎用負債の残高を別モデルから自動算出し、負債合計の初期値として表示する。ユーザーは実際の残高に合わせて必要に応じて上書き可能とする。

---

## 4. 自動計算

入力値から以下を自動計算する。

- 資産合計
- 負債合計
- 純資産

計算:

```
資産合計 = 現金 + 株式 + 投資信託 + NISA + iDeCo + その他投資 + 不動産
純資産 = 資産合計 - 負債合計
```

---

## 5. 前回値の引き継ぎ

新しい実績入力を開始した際:

1. 直近の実績データを取得
2. 各カテゴリの残高を初期値として表示
3. ユーザーは変更のあった項目のみ更新
4. 保存時に新しい実績スナップショットを作成

過去の実績データそのものは変更しない。

---

## 6. UI構成案

### 6.1 上部

- タイトル「資産実績を入力」
- 実績日
- 前回実績日
- 前回からの経過日数

### 6.2 メイン入力

カテゴリごとのカードまたは入力行を縦に並べる。

各行:

- カテゴリ名
- 前回値
- 今回値入力
- 前回差分

例:

```
現金 / 預金
前回 2,300,000円
今回 [ 2,450,000 ]
差分 +150,000円
```

### 6.3 サマリー

入力中もリアルタイムに表示:

- 資産合計
- 負債合計
- 純資産
- 前回比

### 6.4 操作

- 保存
- キャンセル

保存成功後:

- 実績詳細または実績一覧へ遷移
- ダッシュボードの最新実績サマリーを更新

---

## 7. Mobile

- 1カラム
- 数値入力欄は大きくする
- 数字キーボードを使用
- 保存ボタンは画面下部に固定する候補
- カテゴリごとの入力カードは十分なタップ領域を確保

---

## 8. Web

- 1〜2カラム構成を候補とする
- 左側にカテゴリ入力
- 右側にリアルタイムサマリーを固定表示する候補
- キーボード操作で次の入力欄へ移動しやすくする

---

## 9. バリデーション

- 金額は0以上を基本とする
- 負債は正数として入力し、計算時に差し引く
- 未入力カテゴリは前回値を維持
- 初回実績で前回値が存在しない場合は0円を初期値とする
- 極端に大きな数値の場合も保存自体は可能にし、確認UIを検討する
