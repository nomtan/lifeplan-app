# ライフプラン管理アプリ 仕様書

最終更新: 2026-09-01

## 1. 文書の目的

本書は、ライフプラン管理アプリのプロダクト仕様を継続的に整理するための基準文書とする。

仕様は次の状態で管理する。

- **確定**: ユーザーとの壁打ちで採用が決定した内容
- **検討中**: 有力案だが、まだ決定していない内容
- **未決定**: 今後の質問・検討が必要な内容

## 2. プロダクト概要

### 2.1 コンセプト【確定】

ユーザーが人生に関わるお金の計画と将来の収支見通しを、年表ベースのGUIで直感的に把握できるサービス。

ライフプランナーやファイナンシャルプランナーが作成するようなライフプラン表を、専門知識が少ない個人でも自分で作成・更新できることを目指す。

### 2.2 主な対象データ【確定】

- 給与などの収入
- 日常生活費などの継続支出
- 結婚、出産、進学、住宅購入などのライフイベント
- 子どもの学費
- 住宅ローン、家賃、自宅維持費
- その他、将来の収支に影響する項目

### 2.3 提供プラットフォーム【確定】

- Web
- iOS
- Android

## 3. 技術方針

### 3.1 フロントエンド【確定】

- Web: Next.js
- iOS / Android: Expo + React Native
- UI: HeroUIを採用予定

> HeroUIのWeb版とReact Native版では利用可能なコンポーネントや成熟度が異なる可能性があるため、デザインシステムやロジックの共有範囲は実装前に検証する。

### 3.2 バックエンド【確定】

Cloudflareを中心に構成する。

具体的なサービス構成は未決定。

候補:

- API: Cloudflare Workers
- データベース: Cloudflare D1
- ファイル保存: Cloudflare R2
- 非同期処理: Cloudflare Queues
- キャッシュ・一時データ: Cloudflare KV

### 3.3 認証【検討中】

認証方法:

- Sign in with Apple
- Googleログイン
- メールアドレス

認証基盤の第一候補はClerk。

Next.jsとExpoの双方に公式SDKがあり、MVPを早く構築しやすい。一方で、料金上限、Cloudflare Workersとのトークン検証、Appleログインの実機動作、将来の移行コストを事前に検証してから正式決定する。

## 4. 現時点のコア体験【検討中】

1. ユーザーが本人と家族の基本情報を登録する
2. 現在の収入・支出・資産・負債を入力する
3. 年表上に将来のライフイベントを配置する
4. イベントに一時的または継続的な収入・支出を設定する
5. 年ごとの収支と資産残高の推移を自動計算する
6. グラフや年表から資金不足が起きる時期と要因を確認する
7. 条件を変えた複数のプランを比較する

## 5. 主要機能候補【未決定】

- 初回入力を支援するオンボーディング
- 家族構成と年齢の管理
- 収入、固定費、変動費の管理
- 資産、負債、住宅ローンの管理
- ライフイベントの年表編集
- 教育費シミュレーション
- 住宅費・維持費シミュレーション
- 老後資金・年金シミュレーション
- 年次キャッシュフロー
- 資産残高推移グラフ
- 複数シナリオの作成と比較
- 入力値に対する注意事項・根拠の表示
- データのエクスポート
- 共有・共同編集

## 6. 非機能要件候補【未決定】

- 金融・家族情報を扱うことを前提としたセキュリティ
- 通信時・保存時の暗号化方針
- アカウントおよび全データの削除
- バックアップと復元
- Web・モバイル間のデータ同期
- オフライン対応範囲
- アクセシビリティ
- 日本円以外の通貨対応
- 税制・社会保障制度改定への対応
- 計算結果が将来を保証しない旨の免責表示

## 7. MVPの範囲【未決定】

MVPに含める機能、対象ユーザー、計算期間、収支項目の粒度、シナリオ比較の有無は今後決定する。
